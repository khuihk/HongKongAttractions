# HongKongAttractions

SwiftUI iOS app:
- 2-second splash with Hong Kong night scene
- List of attractions (text left, image right)
- Tap image → modal popup with details

## Setup
1. Open Xcode → File → Open... → select the `HongKongAttractions` folder.
2. In `Assets.xcassets`, add images:
   - hongkongnight
   - peak
   - starferry
   - temple
3. Select a simulator (e.g., iPhone 15) → Run.

## Requirements
- Xcode 15+
- iOS 16+
